# Stocked out is terminal

A stocked-out vehicle cannot return to in stock, and its VIN cannot be added again. Taking it back would reopen inventory age: the days it was gone would have to count, or the first stay would have to be discarded. This assessment keeps the departure and stops. A deal that falls through is out of scope. While the vehicle is stocked out, the only correction is the stocked-out on date.

## Considered options

- Reopen the same vehicle and keep the original entered-on date. The gap counts toward inventory age.
- Reopen it and set entered on to the day it returns. The earlier stay is no longer visible, which fights the reason departed vehicles were kept.
