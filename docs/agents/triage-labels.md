# Triage labels

The issue `Status:` line is the role name.

| Status | Meaning |
|--------|---------|
| `needs-triage` | Maintainer needs to evaluate |
| `needs-info` | Waiting on the reporter |
| `ready-for-agent` | Specified enough for an agent |
| `ready-for-human` | Needs a person |
| `wontfix` | Will not be done |

When a skill names a role, write that string as `Status:`.
