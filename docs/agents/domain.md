# Domain docs

This repo has one context.

- `GLOSSARY.md` — use these words in issues, tests, and UI. When a term is missing, do not invent a synonym; note the gap.
- `docs/adr/` — read the ADRs for the area you are changing. If the work contradicts one, say so (`Contradicts ADR-000N…`) instead of overriding it.

If either file is missing, continue. Create it when a term or a decision is actually resolved.
